# v0.5 릴리스 테스트 매트릭스

릴리스 전 아래 항목을 모두 확인한다. 계산값은 사전검토용이며, 실제 현장 적용은 작업허가 절차와 실측으로 별도 확인한다.

| 구분 | 대상 | 필수 확인 | 판정 |
|---|---|---|---|
| Android | Chrome / WebView | 최초 실행 시 기본 공간 1개·송풍기 1개, 단계 전환 위치, 임시저장·복원, 한국어·태국어·아랍어 화면 | ☐ |
| Android | Samsung Internet | 숫자 입력, 장비 추가·삭제, CFM/ft 입력, JSON 저장·불러오기, 인쇄 호출 | ☐ |
| iPhone | Safari | 화면 언어 전환, 단계 전환, 가로·세로 회전, 임시저장, A4/Letter 인쇄 미리보기 | ☐ |
| Desktop | Chrome | 1280px 및 1920px 화면, 키보드 이동, 오류 안내, JSON 세션, PDF 저장 | ☐ |
| Desktop | Edge | 위 Chrome 항목과 A4/Letter PDF 저장 | ☐ |
| RTL | Arabic / Persian / Urdu | 문단 우측 정렬, 수치·단위·날짜 좌→우 고정, 표 열 순서·서명란·PDF | ☐ |
| 소수점 | French / German / Portuguese | `1,5` 입력이 1.5로 계산·저장·복원되는지 | ☐ |
| 미국 단위 | US profile | ft·ft³·CFM 입력이 SI 내부값으로 변환되고 결과에 병기되는지 | ☐ |
| 법규 | 7개 프로필 | 프로필 범위, 검토 기준일, 검토자, 다음 검토일, 공식 출처 표시 | ☐ |
| 미검증 관할 | Unverified local jurisdiction | 현지 EHS 검토 필수 경고가 화면·인쇄물에 표시되는지 | ☐ |
| 인쇄 | A4 / Letter | 표 절단, 서명란, 추적 메타데이터, 번역 페이지, 1~2페이지 흐름 | ☐ |

## 스크린샷 증빙

각 릴리스에서는 아래 8개를 캡처해 버전 폴더에 보관한다.

1. Android 한국어 1단계
2. Android 송풍기 표 및 CFM 입력
3. iPhone 세로 화면
4. RTL 결과·인쇄 미리보기
5. 쉼표 소수점 입력 결과
6. A4 PDF 첫 페이지
7. US Letter PDF 첫 페이지
8. 미검증 관할 경고 및 추적 메타데이터

모든 항목이 통과하기 전에는 EXE/APK 배포본을 생성하지 않는다.
