안전 고지: 계산값만으로 출입을 허가하지 마십시오. 작업 전·재개 전과 작업 중에는 현장 대기를 측정·평가하고, 현행 법규 및 사업장 작업허가 절차를 따르십시오.

1. 안전 기준과 화면 언어

화면 언어와 법규 프로필은 별개입니다. 실제 작업 장소에 맞는 안전 기준을 먼저 선택하고, 화면 언어는 사용자가 읽기 편한 언어로 선택합니다.

법규 원문과 사업장 절차가 번역문보다 우선합니다.

한국어 시작 화면: 안전 기준 프로필, 인쇄 용지, 단위 설정

2. 계산 방식과 공간 체적

A

지속 발생원이 특정되지 않으면 체적배수법을 사용합니다. 공간을 더하거나 빼서 실제 공기 체적을 입력합니다.

B

발생량을 아는 경우에는 희석법(발생량 입력)을, 발생량을 모르는 경우에는 측정값 기반 역산을 사용합니다.

3. 작업 조건과 송배풍기 매칭

3

초기 급기 배수와 작업 중 유지 환기횟수는 적용 프로필과 현장 위험성평가에 맞춰 확인합니다.

4

계산 결과에서 최초 급기량과 작업 중 유지 환기량을 구분해 확인합니다.

5

정격풍량×효율, 제조사 운전점 또는 현장 실측 중 실제 근거에 맞는 장비 풍량을 선택하고, 필요 대수와 여유율을 확인합니다.

4. 결과서 인쇄

결과서는 작업허가서에 붙이는 계획 참고자료입니다. 필요하면 번역 보조 페이지를 추가할 수 있으나, 현장 대기 측정·법규 원문·사업장 절차를 대체하지 않습니다.
