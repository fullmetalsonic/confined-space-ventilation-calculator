Safety notice: Never authorize entry from calculations alone. Before entry, re-entry, and during work, measure and evaluate the atmosphere and follow current requirements and the site work-permit procedure.

1. Safety profile and UI language

Screen language does not select the law. First select the safety jurisdiction profile that applies to the workplace, then select the language that helps the user read the interface.

The official legal text and site procedure take precedence over translations.

English start screen: jurisdiction profile, paper, and units

2. Calculation method and space volume

A

Use volume exchange when no continuous source is identified. Add or subtract areas to enter the actual air volume.

B

Use the known generation-rate method when the generation rate is known; use the measured-concentration method only when the required measurement data are available.

3. Work conditions and blower matching

3

Confirm initial-purge and continuous-airflow criteria against the selected profile and site risk assessment.

4

Review the initial purge requirement separately from continuous airflow during work.

5

Use the airflow basis that matches the evidence—rated flow with correction, manufacturer operating point, or field measurement—then review required quantity and reserve margin.

4. Print the report

The report is a planning attachment for the work permit. Supplementary translations can be printed, but they never replace atmospheric measurement, the official source, or the site procedure.
