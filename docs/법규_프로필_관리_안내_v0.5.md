# 법규 프로필 관리 안내 v0.5

법규 프로필의 원본은 [regulatory_profiles_v05.json](../data/regulatory_profiles_v05.json)이다. HTML 코드에 법규 문구를 직접 추가하지 않는다.

## 갱신 절차

1. 해당 국가의 현행 공식 원문과 시행일을 확인한다.
2. JSON의 대상 프로필에서 `rows`, `clauses`, `source`, `url`, `extraSources`를 갱신한다.
3. `reviewedAt`, `reviewer`, `nextReviewDue`, `profileVersion`을 반드시 갱신한다.
4. 현지 EHS 승인 여부에 맞춰 `approvalStatus`, `approvalNote`를 갱신한다. 승인되지 않은 경우에는 `local-ehs-approval-pending` 상태를 유지한다.
5. 해당 국가의 문서 관행에 맞춰 `regionalPreferences`의 `paper`, `resultUnit`, `inputUnit`, `dateFormat`을 확인한다.
6. `python scripts/build_global_v05_html.py`로 HTML을 생성한다.
7. `node scripts/audit_v05_html.js`를 실행한다.
8. 릴리스 테스트 매트릭스의 기기·인쇄 항목을 확인한다.

## 프로필 원칙

- 화면 언어와 법규 프로필은 별개다.
- `unverified`는 현지 법규가 없다는 뜻이 아니라, 이 도구가 검토·반영한 현지 프로필이 없다는 뜻이다.
- 미검증 관할에서는 회사 절차와 현지 EHS 검토를 거친 기준만 사용한다.
- 법규 프로필의 표 수치는 작업허가·실측·SDS 검토를 대체하지 않는다.
- 프로필 전환은 단위·용지·날짜 형식을 자동 변경하지 않는다. 화면에 표시되는 **추천 적용**을 사용자가 직접 눌렀을 때만 지역별 문서 설정이 바뀐다.
- `approvalStatus`가 `local-ehs-approved`가 아닌 프로필은 공식 출처를 반영했더라도 현지 사업장 적용 승인이 완료되었다는 뜻이 아니다.
