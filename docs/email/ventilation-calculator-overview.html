밀폐공간 환기량 산정 도구
Confined Space Ventilation Calculator

최초 급기량 · 작업 중 유지 환기량 · 송배풍기 매칭 / Initial purge · Continuous airflow · Blower matching

밀폐공간 작업 전 환기 계획을 정리하는 오프라인 계산 도구입니다. 안전 기준 프로필, 계산 방식, 공간 체적과 작업 조건을 입력하면 필요한 환기량과 보유 장비의 필요 대수·여유율을 비교할 수 있습니다.

An offline planning tool for confined-space ventilation. Select the safety profile, method, space volume, and work conditions to compare required airflow with available blowers.

사용 흐름 / Workflow

1. 작업 장소의 안전 기준 프로필을 선택합니다. / Select the applicable safety jurisdiction profile.

2. 계산 방식, 공간 체적, 작업 조건을 입력합니다. / Enter the method, space volume, and work conditions.

3. 최초 급기량과 유지 환기량을 확인하고 보유 송배풍기를 매칭합니다. / Review initial purge and continuous airflow, then match available blowers.

4. 결과서는 작업허가서에 붙이는 계획 참고자료로 사용합니다. / Use the result report as a planning attachment to the work permit.

안전 고지 / Safety notice: 계산값만으로 출입을 허가하지 마십시오. 작업 전·재개 전과 작업 중 현장 대기를 측정·평가하고, 현행 법규와 사업장 작업허가 절차를 따르십시오. / Never authorize entry from calculations alone. Measure and evaluate the atmosphere and follow applicable requirements and the site permit procedure.
