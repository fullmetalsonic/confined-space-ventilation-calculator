# v0.6 개발 구조 / Development Structure

> **English overview:** v0.6 keeps the calculator’s user features and formulas
> while separating the web source into maintainable modules. Edit only
> `src/`; the single-file HTML and `app.py` are generated outputs. After a
> change, build the web bundle, synchronize the desktop wrapper, and run the
> verification script before packaging an APK or EXE. The Korean sections below
> are the detailed working record.

v0.6은 v0.5의 사용자 기능과 계산식을 유지하면서, 단일 HTML에 섞여 있던 스타일과
JavaScript를 수정 목적별로 분리한 유지보수 구조입니다. 배포 HTML은 여전히 하나의
파일이므로 인터넷 연결 없이 더블클릭으로 실행할 수 있습니다.

## 수정 기준

수정은 `src/`에서만 합니다. `dist/html/밀폐공간_환기량_산정_도구_v0.6.html`과
`app.py`는 생성물입니다. 직접 편집하지 않습니다.

| 위치 | 담당 기능 |
| --- | --- |
| `src/index.html` | 화면 마크업과 모듈 로드 순서 |
| `src/styles/app.css` | 기본 UI·인쇄·v0.3/v0.4 스타일 |
| `src/styles/v05.css` | v0.5 글로벌 운영 확장 스타일 |
| `src/scripts/core.js` | 공통 상태 |
| `src/scripts/i18n.js` | 화면·인쇄 다국어 텍스트 |
| `src/scripts/navigation.js` | 마법사 단계 이동 |
| `src/scripts/geometry.js` | 공간 형상과 체적 산정 |
| `src/scripts/calculations.js` | 환기량 계산과 결과 표시 |
| `src/scripts/fans.js` | 송배풍기 유효풍량·필요 대수·단위 변환 |
| `src/scripts/platform.js` | 인쇄와 브라우저/Windows/Android 저장 분기 |
| `src/scripts/reporting.js` | 결과 보고서와 다국어 인쇄물 |
| `src/scripts/session.js` | 세션 JSON 저장·복원 |
| `src/scripts/init.js` | 화면 초기화 보조 기능 |
| `src/scripts/bootstrap.js` | DOM 준비 후 초기 화면 설정 |
| `src/scripts/v05.js` | 법규 프로필·지역 설정·임시저장 등 v0.5 확장 |

## 변경 후 절차

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\build_web.ps1
powershell -ExecutionPolicy Bypass -File .\scripts\sync_desktop_html.ps1
powershell -ExecutionPolicy Bypass -File .\scripts\verify_modular_web.ps1
```

검증이 통과한 뒤에만 Windows EXE 또는 Android APK 빌드에 v0.6 HTML 경로를 넘깁니다.
기존 v0.5 APK와 EXE는 자동으로 갱신되지 않으므로, 새 바이너리가 필요할 때에만
각 빌드 스크립트를 실행합니다.

## 호환성 원칙

- 브라우저·Android WebView의 `file://` 실행 호환성을 위해 JavaScript ES 모듈 import는
  사용하지 않고, 순서가 고정된 일반 script 태그를 사용합니다.
- 단일 HTML 배포본은 위 순서로 CSS·JS를 인라인화합니다.
- HTML 인라인 `onclick`에서 호출하는 함수는 전역 함수로 유지했습니다.
- 안전 관련 계산식과 기본 기준값은 이번 구조 변경에서 수정하지 않았습니다.
